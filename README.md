# Analyse de mes courses Strava

## Description
Analyse exploratoire de mes donnees personnelles de course a pied extraites via l'API Strava.
Ce projet demontre l'extraction de donnees via API REST (OAuth 2.0), le nettoyage et la transformation
de donnees, ainsi que la visualisation de donnees sportives personnelles.

## Apercu des donnees
- 697 courses analysees depuis septembre 2023
- 12.86 km de distance moyenne par course
- 42.78 km distance maximale (marathon)
- 5:20 min/km allure moyenne

![Analyse overview](strava_overview.png)

## Technologies utilisees
- Python : Pandas, Matplotlib, Seaborn
- API Strava : Authentification OAuth 2.0
- Jupyter Notebook : Analyse interactive
- Git / GitHub : Versionnement du projet
